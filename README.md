# Student Record Management System

A simple Student Record Management System built using Python.

## Features

### CLI Version
- Add student
- View students
- Search student
- Delete student

### GUI Version
- Add student
- View students
- User-friendly interface using Tkinter

## Technologies Used
- Python
- Tkinter (GUI)
- File Handling

## How to Run

### CLI
```bash
python student_cli.py
```

### GUI
```bash
python student_gui.py
```
